# 日记模块完整实现方案

## 一、项目背景与目标

### 1.1 当前状态
日记模块目前处于极早期阶段，仅有基础框架：
- ✅ 路由配置已完成 (`/dairy`)
- ✅ 视图组件已创建 (`DairyView.vue`)
- ❌ 主内容组件为空 (`DairyMain.vue`)
- ❌ 侧边栏组件为空 (`DairySidebar.vue`)
- ❌ 无独立的状态管理
- ❌ 无数据类型定义
- ❌ 组件引用错误（`DairyView` 引用了不存在的 `TalkMain`）

### 1.2 实现目标
参考博客模块的成熟实现，构建日记功能模块，提供：
- 日记列表展示（时间轴形式）
- 日记详情查看
- 按日期筛选（年/月/日）
- 心情标签管理
- 搜索功能
- 统计数据展示

## 四、状态管理设计

### 4.1 日记 Store (`src/stores/dairy.ts`)

```typescript
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import type { DairyEntry, DairyMeta, DateGroup, MoodStat } from '@/types/dairy'

/**
 * 日记模块 Pinia Store
 */
export const useDairyStore = defineStore('dairy', () => {
  // ========== 状态 (State) ==========
  /** 所有日记条目列表 */
  const entries = ref<DairyEntry[]>([])

  /** 加载状态标识 */
  const loading = ref(false)

  /** 加载过程中的错误信息 */
  const error = ref<string | null>(null)

  /** 日记是否已加载完成的标识 */
  const isLoaded = ref(false)

  /** 当前选中的日期筛选（格式：YYYY-MM） */
  const selectedDate = ref<string>('all')

  /** 当前选中的心情筛选 */
  const selectedMood = ref<string>('all')

  /** 搜索关键词 */
  const searchKeyword = ref<string>('')

  // ========== 计算属性 (Getters) ==========
  /**
   * 按日期分组的日记列表（用于时间轴展示）
   */
  const dateGroups = computed<DateGroup[]>(() => {
    const groups = new Map<string, DairyEntry[]>()

    entries.value.forEach(entry => {
      const date = new Date(entry.meta.date)
      const key = `${date.getFullYear()}-${String(date.getMonth() + 1).padStart(2, '0')}`

      if (!groups.has(key)) {
        groups.set(key, [])
      }
      groups.get(key)!.push(entry)
    })

    return Array.from(groups.entries())
      .map(([key, entries]) => {
        const [year, month] = key.split('-').map(Number)
        return { year, month, entries }
      })
      .sort((a, b) => {
        if (a.year !== b.year) return b.year - a.year
        return b.month - a.month
      })
  })

  /**
   * 心情统计
   */
  const moodStats = computed<MoodStat[]>(() => {
    const moodMap = new Map<string, number>()

    entries.value.forEach(entry => {
      const mood = entry.meta.mood
      moodMap.set(mood, (moodMap.get(mood) || 0) + 1)
    })

    const total = entries.value.length

    return Array.from(moodMap.entries()).map(([mood, count]) => ({
      mood: mood as any,
      count,
      percentage: total > 0 ? Math.round((count / total) * 100) : 0
    }))
  })

  /**
   * 可用的年月列表（用于筛选器）
   */
  const availableDates = computed<string[]>(() => {
    const dates = new Set<string>()

    entries.value.forEach(entry => {
      const date = new Date(entry.meta.date)
      const key = `${date.getFullYear()}-${String(date.getMonth() + 1).padStart(2, '0')}`
      dates.add(key)
    })

    return Array.from(dates).sort().reverse()
  })

  /**
   * 根据筛选条件过滤后的日记列表
   */
  const filteredEntries = computed<DairyEntry[]>(() => {
    let result = entries.value

    // 日期筛选
    if (selectedDate.value !== 'all') {
      result = result.filter(entry => {
        const entryDate = entry.meta.date.substring(0, 7) // YYYY-MM
        return entryDate === selectedDate.value
      })
    }

    // 心情筛选
    if (selectedMood.value !== 'all') {
      result = result.filter(entry => entry.meta.mood === selectedMood.value)
    }

    // 搜索关键词
    if (searchKeyword.value.trim()) {
      const keyword = searchKeyword.value.toLowerCase()
      result = result.filter(entry =>
        entry.meta.title.toLowerCase().includes(keyword) ||
        entry.content.toLowerCase().includes(keyword) ||
        entry.meta.tags.some(tag => tag.toLowerCase().includes(keyword))
      )
    }

    return result
  })

  /**
   * 所有标签及其使用次数
   */
  const tags = computed<Map<string, number>>(() => {
    const tagMap = new Map<string, number>()

    entries.value.forEach(entry => {
      entry.meta.tags.forEach(tag => {
        tagMap.set(tag, (tagMap.get(tag) || 0) + 1)
      })
    })

    return tagMap
  })

  // ========== 方法 (Actions) ==========
  /**
   * 加载所有日记条目
   */
  async function loadDairyEntries() {
    if (isLoaded.value && entries.value.length > 0) {
      return
    }

    loading.value = true
    error.value = null

    try {
      // 动态导入所有日记 Markdown 文件
      const dairyModules = import.meta.glob<string>('@/docs/dairy/**/*.md', {
        query: '?raw',
        import: 'default'
      })

      const entryList: DairyEntry[] = []
      const filePaths = Object.keys(dairyModules)

      for (const path of filePaths) {
        try {
          const moduleLoader = dairyModules[path]
          if (!moduleLoader) continue

          const rawContent = await moduleLoader()
          const { meta, content } = parseDairyMarkdown(rawContent)

          // 生成 ID（使用日期作为 ID）
          const id = meta.date

          entryList.push({ id, path, meta, content })
        } catch (err) {
          console.error(`处理文件 ${path} 失败：`, err)
          continue
        }
      }

      // 按日期倒序排序
      entryList.sort((a, b) => {
        return new Date(b.meta.date).getTime() - new Date(a.meta.date).getTime()
      })

      entries.value = entryList
      isLoaded.value = true
    } catch (err) {
      error.value = err instanceof Error ? err.message : '加载日记失败'
      console.error('日记加载异常：', err)
    } finally {
      loading.value = false
    }
  }

  /**
   * 根据 ID 获取单篇日记
   */
  function getEntryById(id: string): DairyEntry | undefined {
    return entries.value.find(entry => entry.id === id)
  }

  /**
   * 根据日期获取日记
   */
  function getEntryByDate(date: string): DairyEntry | undefined {
    return entries.value.find(entry => entry.meta.date === date)
  }

  /**
   * 设置日期筛选
   */
  function setDateFilter(date: string) {
    selectedDate.value = date
  }

  /**
   * 设置心情筛选
   */
  function setMoodFilter(mood: string) {
    selectedMood.value = mood
  }

  /**
   * 设置搜索关键词
   */
  function setSearchKeyword(keyword: string) {
    searchKeyword.value = keyword
  }

  /**
   * 重置所有筛选条件
   */
  function resetFilters() {
    selectedDate.value = 'all'
    selectedMood.value = 'all'
    searchKeyword.value = ''
  }

  return {
    // State
    entries,
    loading,
    error,
    isLoaded,
    selectedDate,
    selectedMood,
    searchKeyword,
    // Getters
    dateGroups,
    moodStats,
    availableDates,
    filteredEntries,
    tags,
    // Actions
    loadDairyEntries,
    getEntryById,
    getEntryByDate,
    setDateFilter,
    setMoodFilter,
    setSearchKeyword,
    resetFilters
  }
})
```

## 七、Markdown 文档格式规范

**文件路径：** `src/docs/dairy/2024/01/2024-01-15.md`

```markdown
---
title: 新年新开始
date: 2024-01-15
mood: excited
weather: sunny
tags: [新年, 目标, 计划]
summary: 今天是2024年的第15天，我想为新的一年制定一些目标。
---

## 新年计划

今天是新的一年，我希望能够：

1. 坚持写日记
2. 学习新的技术
3. 多运动

今天天气很好，心情也格外愉悦！希望这一年能够顺顺利利。
```

### 7.2 文件命名规范

- 格式：`YYYY-MM-DD.md`
- 示例：`2024-01-15.md`
- 路径结构：`src/docs/dairy/YYYY/MM/YYYY-MM-DD.md`

### 7.3 必需字段

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| title | string | ✅ | 日记标题 |

| mood | MoodType | ✅ | 心情标签 |
| weather | WeatherType | ❌ | 天气标签（可选） |
| tags | string[] | ❌ | 标签列表（可选） |
| summary | string | ❌ | 摘要（可选，默认取正文前100字） |

## 十一、注意事项

1. **文件命名一致性**：确保所有日记文件遵循 `YYYY-MM-DD.md` 格式
2. **日期唯一性**：同一天只能有一篇日记（或支持多篇，需调整ID生成逻辑）
3. **心情标签规范**：限制在预定义的8种心情类型中
4. **性能优化**：大量日记时考虑分页或虚拟滚动
5. **隐私保护**：日记内容默认私密，暂不设计公开分享功能
6. **移动端适配**：确保在移动设备上有良好的阅读体验
