# 精致博客首页开发指导提示词（适配Claude）

## 一、核心需求明确（必看）

开发一个视觉精致、交互流畅的博客首页，核心元素需满足以下3点，且整体风格简约高级、细节打磨到位：

1. **背景层**：全屏展示高清壁纸（适配不同屏幕分辨率，无拉伸/变形/黑边，支持响应式适配）；

2. **核心文案层**：页面垂直+水平居中显示“欢迎来到XX的博客”（XX替换为实际昵称），文案需实现“自动书写”动画（模拟打字效果，含光标闪烁，节奏自然不卡顿）；

3. **交互按钮层**：欢迎语正下方（或页面中下位置）放置一个“立即进入”按钮，按钮需有hover交互效果（如颜色渐变、轻微缩放、阴影变化等），点击后可跳转至博客内容页（或首页后续区域）。

## 二、技术栈与适配要求

1. 技术栈：基于 Vue3 + TypeScript + Vite 开发（前端框架固定，需贴合该技术栈语法规范）；

2. 样式要求：使用 CSS/SCSS 编写，支持 Tailwind CSS（优先推荐，效率更高），需保证页面在 PC 端（主流分辨率：1920*1080、1366*768）、平板端适配正常；

3. 性能要求：壁纸加载优化（可实现懒加载、渐进式加载），动画效果流畅（无卡顿、无抖动），代码结构清晰、可维护（含必要注释）；

4. 兼容性要求：适配 Chrome、Edge、Firefox 主流浏览器最新3个版本。

## 三、细节优化要求（精致感核心，重点实现）

### 1. 背景壁纸优化

- 壁纸选择：建议选用低饱和、高清晰度的风景图/简约插画（避免色彩过于艳丽刺眼，影响文案可读性）；

- 显示效果：设置背景固定（background-attachment: fixed），缩放模式为 cover（background-size: cover），居中对齐（background-position: center center），可叠加一层半透明遮罩（如 rgba(0,0,0,0.2)），提升文案对比度和页面高级感；

- 加载优化：实现壁纸懒加载（先显示纯色背景/低清缩略图，加载完成后平滑切换），避免页面空白等待。

### 2. 自动书写动画优化

- 打字效果：每个文字逐字出现，打字速度可配置（建议 100-150ms/字，节奏自然）；

- 光标效果：打字结束前，光标（竖线 |）持续闪烁（频率 500ms 切换显示/隐藏），打字完成后光标可保留或缓慢消失；

- 文案样式：字体选用无衬线字体（如 Inter、思源黑体），字号适配响应式（PC端建议 2.5rem-3rem，平板端同比缩小），颜色为白色（或浅灰色，需与背景对比度≥4.5:1，保证可读性），可添加轻微文字阴影（如 text-shadow: 0 2px 4px rgba(0,0,0,0.3)），增强层次感。

### 3. 立即进入按钮优化

- 位置：位于欢迎语正下方 20-30px 处，水平居中，与页面底部保持一定距离（避免贴底，PC端建议距离底部 100px 以上）；

- 样式：按钮为圆角矩形（border-radius: 30px-50px，圆润不生硬），背景色建议选用低饱和亮色（如淡蓝色、淡紫色，与背景区分明显但不突兀），文字为白色、加粗，padding 为 12px 32px（大小适中，便于点击）；

- 交互：hover 时实现平滑效果（如背景色加深、按钮轻微放大 5%-10%、阴影增强，过渡时间 0.3s，动画曲线 ease-in-out），点击时可有轻微按压反馈（如缩放 95%）；

- 额外：按钮可添加淡入动画（页面加载完成后 1.5s 内从透明变为不透明），避免与打字动画冲突。

### 4. 整体页面优化

- 布局：采用 flex 布局实现核心内容（欢迎语+按钮）垂直水平居中，页面高度 100vh（全屏显示，无滚动条，除非壁纸高度超出屏幕）；

- 加载过渡：页面初始化时，可实现背景从纯色到壁纸、核心内容从透明到显示的平滑过渡，提升首次加载体验；

- 无多余元素：页面仅保留核心元素（背景、欢迎语、按钮），无冗余装饰，保证简约精致的视觉风格。

## 四、交付物要求

1. 完整代码文件：包含 Vue 单文件组件（.vue，含 template、script、style 三部分），script 部分需用 TypeScript 编写，类型定义完整；

2. 依赖说明：明确所需依赖包（如动画相关、懒加载相关，若使用 Tailwind 需说明配置方式）及安装命令；

3. 使用说明：简单说明代码使用方法（如替换昵称、更换壁纸、配置跳转路径、调整动画参数等）；

4. 优化建议：针对页面性能、交互细节的额外优化建议（可选）。

## 五、最终效果参考描述

页面加载完成后，首先显示平滑过渡的高清全屏壁纸（带轻微遮罩），随后中间位置开始逐字出现“欢迎来到XX的博客”文字，伴随光标闪烁；打字动画完成后，下方“立即进入”按钮淡入显示；鼠标悬浮在按钮上时，按钮轻微放大并加深背景色，点击后跳转至博客内容页；整体视觉简约高级，交互流畅自然，细节打磨到位，符合精致博客首页的定位。
