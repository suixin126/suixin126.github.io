# 井字棋游戏实现方案文档

## 一、设计概述

### 1.1 设计目标

开发一款完整、精致、有趣的井字棋游戏，满足「双人对战」「人机对战（三种难度）」两大核心需求，同时兼顾视觉美观、交互流畅、AI智能，打造可玩性强、体验优秀的轻量级网页游戏。

### 1.2 适用场景

个人博客游戏模块，适配PC端与移动端，支持访客快速开始游戏、挑战不同难度AI，无需安装，主打「休闲摸鱼」「脑力锻炼」场景，可作为博客游戏模块的首个示范游戏。

### 1.3 核心原则

- **完整性**：覆盖游戏全流程（开始→对战→结算→重开），无功能缺失；
- **智能性**：AI算法分层设计（随机→策略→Minimax），满足不同水平玩家；
- **美观性**：视觉设计精致，动画流畅，与博客整体风格统一；
- **易用性**：操作路径短（点击即下棋），状态反馈清晰，新手无门槛；
- **可扩展**：代码结构清晰，预留扩展接口（历史记录、音效、主题）。

## 二、功能模块设计

### 2.1 游戏模式

| 模式 | 说明 | 实现要点 |
|------|------|----------|
| **双人对战** | 本地两人轮流下棋 | 简单的玩家切换逻辑，无需AI |

## 四、核心逻辑实现

### 4.1 游戏主逻辑（useTicTacToe.ts）

#### 核心函数设计

| 函数名 | 功能 | 参数 | 返回值 |
|--------|------|------|--------|
| `makeMove(index)` | 玩家下棋 | 格子索引(0-8) | void |
| `checkWinner()` | 检查胜负 | 无 | Player \| null |
| `checkDraw()` | 检查平局 | 无 | boolean |
| `resetGame()` | 重置游戏 | 无 | void |
| `aiMove()` | AI下棋 | 无 | Promise\<number\> |
| `resetScores()` | 重置比分 | 无 | void |
| `changeMode(mode)` | 切换模式 | GameMode | void |

#### 状态管理
```typescript
import { ref, computed } from 'vue'

export function useTicTacToe() {
  // 状态定义
  const board = ref<CellValue[]>(Array(9).fill(null))
  const currentPlayer = ref<Player>('X')
  const winner = ref<Player | null>(null)
  const isDraw = ref<boolean>(false)
  const gameStatus = ref<GameStatus>('ready')
  const gameMode = ref<GameMode>('pvp')
  const scores = ref<GameScores>({ X: 0, O: 0, draws: 0 })
  const winningLine = ref<number[] | null>(null)
  const moveCount = ref<number>(0)

  // 获胜组合（8种）
  const WINNING_COMBINATIONS = [
    [0, 1, 2], [3, 4, 5], [6, 7, 8], // 横向
    [0, 3, 6], [1, 4, 7], [2, 5, 8], // 纵向
    [0, 4, 8], [2, 4, 6]             // 斜向
  ]

  // 检查获胜
  function checkWinner(): Player | null {
    for (const combination of WINNING_COMBINATIONS) {
      const [a, b, c] = combination
      if (
        board.value[a] &&
        board.value[a] === board.value[b] &&
        board.value[a] === board.value[c]
      ) {
        winningLine.value = combination
        return board.value[a]
      }
    }
    return null
  }

  // 检查平局
  function checkDraw(): boolean {
    return board.value.every(cell => cell !== null) && !winner.value
  }

  // 下棋
  function makeMove(index: number): void {
    // 验证合法性
    if (
      board.value[index] !== null ||
      winner.value ||
      gameStatus.value !== 'playing'
    ) {
      return
    }

    // 更新棋盘
    board.value[index] = currentPlayer.value
    moveCount.value++

    // 检查胜负
    const win = checkWinner()
    if (win) {
      winner.value = win
      gameStatus.value = 'finished'
      scores.value[win]++
      return
    }

    // 检查平局
    if (checkDraw()) {
      isDraw.value = true
      gameStatus.value = 'finished'
      scores.value.draws++
      return
    }

    // 切换玩家
    currentPlayer.value = currentPlayer.value === 'X' ? 'O' : 'X'

    // AI回合（PVE模式）
    if (gameMode.value.startsWith('pve') && currentPlayer.value === 'O') {
      aiMove()
    }
  }

  // AI下棋
  async function aiMove(): Promise<void> {
    // 简单AI：随机
    if (gameMode.value === 'pve-easy') {
      const emptyIndices = board.value
        .map((cell, idx) => cell === null ? idx : null)
        .filter(idx => idx !== null) as number[]

      const randomIndex = emptyIndices[
        Math.floor(Math.random() * emptyIndices.length)
      ]
      makeMove(randomIndex)
    }

    // 中等AI：策略
    else if (gameMode.value === 'pve-medium') {
      const move = getBestMove('medium')
      if (move !== null) makeMove(move)
    }

    // 困难AI：Minimax
    else if (gameMode.value === 'pve-hard') {
      const move = getBestMove('hard')
      if (move !== null) makeMove(move)
    }
  }

  // 重置游戏
  function resetGame(): void {
    board.value = Array(9).fill(null)
    currentPlayer.value = 'X'
    winner.value = null
    isDraw.value = false
    gameStatus.value = 'ready'
    winningLine.value = null
    moveCount.value = 0
  }

  // 重置比分
  function resetScores(): void {
    scores.value = { X: 0, O: 0, draws: 0 }
  }

  // 切换模式
  function changeMode(mode: GameMode): void {
    gameMode.value = mode
    resetGame()
    resetScores()
  }

  // 开始游戏
  function startGame(): void {
    resetGame()
    gameStatus.value = 'playing'
  }

  return {
    // 状态
    board,
    currentPlayer,
    winner,
    isDraw,
    gameStatus,
    gameMode,
    scores,
    winningLine,
    moveCount,

    // 方法
    makeMove,
    resetGame,
    resetScores,
    changeMode,
    startGame
  }
}
```

### 4.2 Minimax算法实现

#### 算法原理
Minimax是一种递归算法，用于在零和博弈中寻找最优策略。核心思想：
- **最大化玩家（AI）**：选择得分最高的步骤
- **最小化玩家（人类）**：选择得分最低的步骤（对AI最不利）
- **评分规则**：AI胜 +10分，人类胜 -10分，平局 0分

#### 代码实现
```typescript
// utils/games/minimax.ts

type Player = 'X' | 'O'
type CellValue = Player | null
type Board = CellValue[]

const WINNING_COMBINATIONS = [
  [0, 1, 2], [3, 4, 5], [6, 7, 8],
  [0, 3, 6], [1, 4, 7], [2, 5, 8],
  [0, 4, 8], [2, 4, 6]
]

/**
 * Minimax算法
 * @param board 当前棋盘状态
 * @param depth 搜索深度
 * @param isMaximizing 是否为最大化玩家（AI，O）
 * @returns 当前局面的评分
 */
export function minimax(
  board: Board,
  depth: number,
  isMaximizing: boolean
): number {
  // 检查游戏结束
  const winner = checkWinner(board)
  if (winner === 'O') return 10 - depth  // AI胜，优先快速获胜
  if (winner === 'X') return depth - 10  // 人类胜，优先延迟失败
  if (isBoardFull(board)) return 0       // 平局

  if (isMaximizing) {
    // AI回合：最大化得分
    let bestScore = -Infinity
    for (let i = 0; i < 9; i++) {
      if (board[i] === null) {
        board[i] = 'O'
        const score = minimax(board, depth + 1, false)
        board[i] = null
        bestScore = Math.max(score, bestScore)
      }
    }
    return bestScore
  } else {
    // 人类回合：最小化得分
    let bestScore = Infinity
    for (let i = 0; i < 9; i++) {
      if (board[i] === null) {
        board[i] = 'X'
        const score = minimax(board, depth + 1, true)
        board[i] = null
        bestScore = Math.min(score, bestScore)
      }
    }
    return bestScore
  }
}

/**
 * 获取最佳下棋位置（困难模式）
 */
export function getBestMoveHard(board: Board): number {
  let bestScore = -Infinity
  let bestMove = -1

  for (let i = 0; i < 9; i++) {
    if (board[i] === null) {
      board[i] = 'O'
      const score = minimax(board.slice(), 0, false)
      board[i] = null

      if (score > bestScore) {
        bestScore = score
        bestMove = i
      }
    }
  }

  return bestMove
}

/**
 * 获取最佳下棋位置（中等模式）
 * 策略：优先中心→阻断玩家→随机
 */
export function getBestMoveMedium(board: Board): number {
  // 优先占领中心
  if (board[4] === null) return 4

  // 阻断玩家获胜
  for (const combination of WINNING_COMBINATIONS) {
    const [a, b, c] = combination
    const values = [board[a], board[b], board[c]]
    const xCount = values.filter(v => v === 'X').length
    const nullCount = values.filter(v => v === null).length

    if (xCount === 2 && nullCount === 1) {
      // 找到空位
      if (board[a] === null) return a
      if (board[b] === null) return b
      if (board[c] === null) return c
    }
  }

  // 随机选择空位
  const emptyIndices = board
    .map((cell, idx) => cell === null ? idx : null)
    .filter(idx => idx !== null) as number[]

  return emptyIndices[Math.floor(Math.random() * emptyIndices.length)]
}

// 辅助函数
function checkWinner(board: Board): Player | null {
  for (const combination of WINNING_COMBINATIONS) {
    const [a, b, c] = combination
    if (
      board[a] &&
      board[a] === board[b] &&
      board[a] === board[c]
    ) {
      return board[a]
    }
  }
  return null
}

function isBoardFull(board: Board): boolean {
  return board.every(cell => cell !== null)
}
```

## 八、性能优化

### 8.1 AI性能优化

**问题**：Minimax算法在深度较大时性能下降

**解决方案**：
1. **限制搜索深度**：井字棋最多9步，深度限制在4层足够
2. **Alpha-Beta剪枝**：减少不必要的计算分支
3. **使用Web Worker**：将AI计算移至后台线程，避免阻塞UI

```typescript
// 优化后的Minimax（带Alpha-Beta剪枝）
export function minimaxWithAlphaBeta(
  board: Board,
  depth: number,
  alpha: number,
  beta: number,
  isMaximizing: boolean
): number {
  const winner = checkWinner(board)
  if (winner === 'O') return 10 - depth
  if (winner === 'X') return depth - 10
  if (isBoardFull(board)) return 0

  if (isMaximizing) {
    let maxScore = -Infinity
    for (let i = 0; i < 9; i++) {
      if (board[i] === null) {
        board[i] = 'O'
        const score = minimaxWithAlphaBeta(board, depth + 1, alpha, beta, false)
        board[i] = null
        maxScore = Math.max(score, maxScore)
        alpha = Math.max(alpha, score)
        if (beta <= alpha) break  // 剪枝
      }
    }
    return maxScore
  } else {
    let minScore = Infinity
    for (let i = 0; i < 9; i++) {
      if (board[i] === null) {
        board[i] = 'X'
        const score = minimaxWithAlphaBeta(board, depth + 1, alpha, beta, true)
        board[i] = null
        minScore = Math.min(score, minScore)
        beta = Math.min(beta, score)
        if (beta <= alpha) break  // 剪枝
      }
    }
    return minScore
  }
}
```
